# ⚠️ No borrar: imágenes de las publicaciones de X

Esta carpeta guarda las imágenes y los vídeos de las publicaciones de X de @boardinggate.

- Buffer descarga cada imagen desde su enlace de raw.githubusercontent.com en el momento de publicar. Si se borra esta carpeta, la rama `imagenes-x` o el repositorio, las publicaciones programadas fallan.
- La limpieza es automática: el 1 de enero, abril, julio y octubre se borran las imágenes con más de 3 meses que no necesite ninguna publicación pendiente. No hace falta borrar nada a mano.
- No cierres la [pull request número 1](https://github.com/BoardingGate/REPOSITORIO/pull/1) ni borres la rama `imagenes-x`: la rama es la que aloja las imágenes.

Más información en el [README del repositorio](https://github.com/BoardingGate/REPOSITORIO/blob/imagenes-x/README.md).
